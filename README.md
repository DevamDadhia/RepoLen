# RepoLens: Autonomous Repository AI Engineer

Autonomous codebase inspector and auditor powered by LangChain, ChromaDB, and Groq open-weights inference.

## Features
- Local AST Chunking & SentenceTransformer embeddings
- Autonomous Tool-Calling (tree browsing, semantic search, source reading)
- Interactive Streamlit dashboard

## Deploying to Streamlit Cloud
1. Push app.py, requirements.txt, and README.md to GitHub.
2. Connect repo on share.streamlit.io.
3. Add GROQ_API_KEY in App Settings -> Secrets.
